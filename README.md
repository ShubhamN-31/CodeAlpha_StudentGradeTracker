# 🎓 Student Grade Tracker (JavaFX)

A desktop application built using Java and JavaFX to manage student grades efficiently.

## 🚀 Features

- Add new students
- Update student (double-click to edit)
- Delete selected student
- Clear all records
- Search by name
- Sort by columns
- Automatic grade calculation
- Live statistics (Average, Highest, Lowest)
- Export data to CSV file

## 🛠 Technologies Used

- Java
- JavaFX
- OOP Principles
- ObservableList, FilteredList, SortedList
- File I/O

## 📂 How to Run

1. Clone the repository
2. Open in IntelliJ IDEA
3. Configure JavaFX SDK
4. Run `MainApp.java`
